# Marine Term Translation Repository Conventions

This document outlines the conventions used for naming and organizing marine term translation repositories.

## Repository Naming

Each repository is named using the following format:

```
<VocabularyName>-<LanguageCode>
```

- **VocabularyName**: The short code or name for the vocabulary collection (e.g., `P02`).
- **LanguageCode**: The two-letter ISO language code (e.g., `NL` for Dutch, `FR` for French).

**Example:**
- The Dutch translation for the P02 collection: `P02-NL`
- The French translation for the P02 collection: `P02-FR`

## Purpose

This convention ensures clarity and consistency, making it easy to identify the vocabulary and language for each translation repository.

## Additional Guidelines

- Use uppercase letters for both vocabulary name and language code.
- Avoid spaces or special characters in repository names.
- Each repository should contain documentation specifying the vocabulary and language.
